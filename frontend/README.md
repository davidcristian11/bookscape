# BookScape Frontend

React/Vite frontend for BookScape. The frontend now lives in `frontend/` and talks to a configurable backend URL.

## Setup

```powershell
cd frontend
npm install
Copy-Item .env.example .env
npm run dev -- --host 0.0.0.0
```

Default API URL:

```text
VITE_API_BASE_URL=http://127.0.0.1:8000
VITE_WS_URL=ws://127.0.0.1:8000
VITE_INACTIVITY_TIMEOUT_MS=1800000
```

For LAN or VM demos, set this to the backend machine address, for example:

```text
VITE_API_BASE_URL=http://192.168.1.25:8000
VITE_WS_URL=ws://192.168.1.25:8000
```

Then run Vite on all interfaces:

```powershell
npm run dev -- --host 0.0.0.0
```

For HTTPS/LAN demos:

```text
VITE_API_BASE_URL=https://<LAPTOP_IP>:8000
VITE_WS_URL=wss://<LAPTOP_IP>:8000
```

Then run either Vite's quick HTTPS mode:

```powershell
npm run dev -- --host 0.0.0.0 --https
```

Or set certificate files generated by `mkcert`:

```text
VITE_HTTPS_KEY=../certs/bookscape-key.pem
VITE_HTTPS_CERT=../certs/bookscape-cert.pem
```

and run:

```powershell
npm run dev -- --host 0.0.0.0
```

Auth tokens, refresh tokens, user role/permission data, and token expiry metadata are stored in browser storage for the lab demo. A 401 response clears the active token and keeps the last known user only for offline queue recovery.

## Tests

```powershell
cd frontend
npm test
npm run coverage
npm run test:e2e
```

Playwright expects the backend and frontend dev server to be running unless you set your own `PLAYWRIGHT_BASE_URL`.
